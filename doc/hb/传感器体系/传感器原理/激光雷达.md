### **激光雷达原理**

激光雷达，英文LiDAR（Light Detection and Ranging），核心原理与雷达（无线电波）和声呐（声波）类似，只是它使用的是**激光**作为探测媒介。其基本工作流程可以概括为：**发射激光 → 激光遇到物体反射 → 接收反射信号 → 计算距离和位置**。

#### **1. 核心测距原理**
激光雷达主要采用两种测距技术：

*   **飞行时间法（ToF， Time of Flight）**：这是目前最主流的技术。它测量激光脉冲从发射到被物体反射后接收所经历的时间 `t`。已知光速 `c`，即可计算出距离 `d = (c * t) / 2`。通过高速重复这一过程，并获得海量点的距离数据，就形成了“点云”。
*   **三角测距法**：主要应用于近距离、低成本的2D雷达。它通过发射激光，并在一个已知基线距离的CMOS传感器上接收反射光点。根据光点在传感器上的位置偏移，利用几何三角关系计算出距离。优点是成本低，但测量距离和精度随距离增加而下降。

#### **2. 2D 激光雷达原理**

*   **工作方式**：2D激光雷达通常只有**一个激光发射器和接收器对**。通过一个旋转的镜面（或电机直接带动收发模块），在**一个平面内**（通常是水平面）进行360°旋转扫描。
*   **输出数据**：每发射一次激光，获得一个点的距离和角度信息。旋转一周后，得到在**一个二维平面**上的一圈点数据。这可以看作是这个平面的一个“横截面”轮廓。
*   **简单比喻**：就像在一个平面上不停地玩“激光笔测距仪”，并让它自己旋转一圈。
*   **典型应用**：扫地机器人（构建室内平面地图）、服务机器人（避障和定位）、AGV小车（导航）。

#### **3. 3D 激光雷达原理**

3D激光雷达的核心目标是获得三维空间的点云数据。实现三维扫描有多种技术路径：

*   **机械旋转式（传统主流）**：
    *   **原理**：将多个激光发射-接收对（即“线”，如16线、32线、64线、128线）垂直排布在一个旋转模块上。电机带动整个模块进行360°旋转。
    *   **工作方式**：水平方向上靠机械旋转实现360°覆盖，垂直方向上靠多根固定角度的激光线实现一定俯仰角的覆盖。这样，每一帧数据都形成了一个由多个“圆环”套在一起组成的球状点云。
    *   **比喻**：就像把一个由多个激光笔组成的“扇子”或“竖琴”高速旋转起来。
    *   **特点**：性能好，视场角大，但机械结构复杂、体积大、成本高、耐久性面临挑战。

*   **固态激光雷达（未来趋势）**：
    *   **原理**：取消了大部分或全部机械旋转部件，主要依靠芯片和光学技术实现光束偏转。
    *   **主要技术路线**：
        1.  **MEMS（微机电系统）**：用一个微小的可动镜面来反射激光光束，通过电路控制镜面偏转，实现扫描。是机械和固态的折中方案，体积小，但视场角通常有限。
        2.  **转镜式**：保留一个旋转的镜面来反射固定的激光束，电机只带动轻巧的镜片，而非整个激光器组。稳定性优于全机械旋转。
        3.  **光学相控阵（OPA）**：通过调节阵列中多个发射器的相位差，利用相干原理改变激光束的方向。纯半导体方案，无任何运动部件，是终极发展方向，但目前技术难度大、成本高。
        4.  **Flash（闪光）**：像手电筒一样，一次发射一大片覆盖整个视场的面阵激光，然后通过高分辨率面阵接收器（类似CCD/CMOS）计算每个像素点的距离。真正的纯固态，但探测距离短，易受干扰。

*   **输出数据**：无论采用何种技术，3D激光雷达最终输出的是**三维点云数据**。每个点包含 `(x, y, z)` 坐标，通常还包含反射强度 `(intensity)` 和时间戳 `(timestamp)` 等信息。

### **如何选择激光雷达**

选择激光雷达没有“最好”，只有“最合适”。需要从以下几个维度综合考虑：

#### **1. 明确核心需求（首先要问自己的问题）**
*   **应用场景是什么？** 自动驾驶（车载前向主雷达/补盲雷达）、机器人导航、测绘建模、安防周界、还是工业检测？
*   **需要2D还是3D信息？** 只需要平面地图和避障（2D可能足够），还是需要识别物体的高度、形状、以及地面起伏（必须3D）？
*   **主要测什么？** 是测距避障、SLAM建图、物体分类识别、还是体积测量？
*   **预算范围是多少？** 价格从几百元（2D/单线）到几十万元（高性能车规级）不等。

#### **2. 关键性能参数对比**
基于需求，重点考察以下参数：

| 参数 | 说明与考量 |
| :--- | :--- |
| **测距能力** | **最大测量距离**：在特定反射率（如10%）下能测到的距离。车规主雷达需**150m以上**，机器人**10-50m**常可满足。<br>**最小测量距离**：盲区大小，对近距离避障很重要。 |
| **精度与分辨率** | **测距精度**：通常厘米级。高精度测绘要求毫米级。<br>**角分辨率**：包括水平和垂直角分辨率。决定点云的密集程度。分辨率越高，对细节的分辨能力越强，但数据量也越大。 |
| **视场角** | **水平视场角（FOV）**：360°（机械旋转）或 120°以下（多数固态）。360°适合全局感知，前向广角适合车载主感知。<br>**垂直视场角**：决定上下能看到范围。车载常用25°-40°，机器人或测绘可能需要更广。 |
| **扫描频率（帧率）** | 每秒完成多少次完整扫描（对于非360°雷达，指每秒输出多少次点云）。**越高，对动态物体捕捉越好，延迟越低**。自动驾驶通常需要10-20Hz。 |
| **线数（针对多线雷达）** | 激光束的数量。**线数越高，垂直分辨率越高，点云越密集**，物体顶部信息越丰富，但成本呈指数级上升。16/32线常用于低速自动驾驶，128线用于L4以上。 |
| **抗干扰能力** | 能否在多台同型号雷达同时工作时区分自己的信号（抗串扰），以及对抗阳光等环境光的能力。**车规和工业应用必须考虑**。 |
| **可靠性与环境等级** | **工作温度范围**、**防护等级（IP**）、**抗震抗冲击**（尤其是车载）。**车规级（AEC-Q100，ISO 16750）** 认证要求极为严苛。 |
| **输出接口与功耗** | 常见接口：以太网（UDP/TCP）、CAN、USB等。需与主处理器匹配。功耗影响系统设计和散热。 |
| **尺寸与重量** | 尤其对空间受限的机器人、无人机至关重要。固态雷达通常更具优势。 |

#### **3. 根据典型应用场景的选择建议**

*   **低速自动驾驶/无人物流车**：
    *   **主感知**：16线或32线机械旋转雷达（如VLP-16， RS-32）。
    *   **补盲**：大视场角（水平>120°，垂直>75°）的短距固态雷达（如MEMS或转镜式）。

*   **L4级以上Robotaxi/Robotruck**：
    *   128线或更高线数的机械旋转雷达作为主雷达，配合多个中长距固态雷达。

*   **服务机器人/AGV/扫地机**：
    *   **导航与建图**：单线2D激光雷达（如SICK， Hokuyo， 国产思岚等）完全足够，性价比极高。
    *   **防跌落/低矮障碍物识别**：可增加一个前向的小型固态或2D雷达。

*   **测绘与勘测**：
    *   需要极高的测量精度和点云密度。选择专业测绘级激光雷达（如RIEGL， Velodyne Puck系列），通常与高精度IMU和GNSS集成。

*   **工业自动化/安防**：
    *   根据具体需求选择。体积测量可能需3D，区域警戒可能只需2D。重点考虑环境适应性（粉尘、高温）和安装方式。

#### **4. 其他重要考量因素**

*   **软件与算法支持**：厂商是否提供SDK、驱动、以及基本的点云处理工具？生态是否完善？
*   **数据格式**：输出点云格式是否通用（如ROS下的`sensor_msgs/PointCloud2`）？
*   **品牌与供应链**：是否满足量产需求？交货周期和售后技术支持如何？

### **总结与选择流程**

1.  **定维度**：根据是否需要高度信息，决定选2D还是3D。
2.  **定场景**：明确应用领域，锁定关键性能（如测距、视场角）。
3.  **比参数**：在预算内，对比不同产品的核心参数（测距、精度、视场角、线数、帧率）。
4.  **验可靠**：检查环境适应性、防护等级、认证标准是否符合实际使用环境。
5.  **看生态**：评估易用性、软件支持和供应链稳定性。
