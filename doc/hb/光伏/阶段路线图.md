# 新一代机器人平台建设

## 阶段路线图（6–12 个月）

---

## 一、路线图制定原则

本路线图以**可交付成果**为核心，而非算法完成度，遵循以下原则：

* 每一阶段均可形成可运行系统
* 每一阶段均可进行真实场地验证
* 每一阶段均可对外展示阶段成果
* 风险前移，避免后期系统性返工

目标不是一次性做全，而是**持续可演进**。

---

## 二、总体阶段划分

项目周期划分为四个阶段：

| 阶段 | 时间      | 核心目标    |
| -- | ------- | ------- |
| P0 | 0–1 个月  | 架构与硬件定型 |
| P1 | 2–3 个月  | 样机可跑    |
| P2 | 4–6 个月  | 作业闭环    |
| P3 | 7–12 个月 | 平台化与稳定性 |

---

## 三、阶段详细规划

---

## **P0 阶段：架构与硬件定型（0–1 个月）**

### 目标

完成平台方向与技术路线统一，避免后期反复推翻。

### 主要工作

* 明确产品形态与作业模式
* 确定底盘结构与作业机构形式
* 确定传感器方案（LiDAR / IMU / GNSS）
* 明确 ROS2 架构分层
* 完成总体架构设计文档

### 输出成果

* 产品定义文档
* 系统总体架构设计文档
* 硬件选型清单
* 技术路线冻结（阶段性）

---

## **P1 阶段：样机可跑（2–3 个月）**

### 目标

机器人具备基础运动与定位能力。

### 主要工作

**系统平台**

* ROS2 工程框架搭建
* 节点命名规范与参数体系
* 日志与运行监控机制

**硬件接入**

* 底盘驱动接入
* IMU、编码器、LiDAR 接入
* GNSS 基础定位接入

**定位能力**

* 局部 SLAM 连续位姿估计
* 里程计 + IMU 融合
* 基础 TF 架构打通

### 输出成果

* 机器人可遥控行走
* 可实时显示位姿
* 可在真实场地连续行走不丢位姿

**阶段标志**

> 机器人“能跑、能定位、不崩”。

---

## **P2 阶段：作业闭环（4–6 个月）**

### 目标

完成从出发到作业完成的完整流程闭环。

### 主要工作

**导航与作业**

* GNSS + 局部 SLAM 融合定位
* 到达作业通道规划
* 通道内中心线跟随
* 作业轨迹规划执行

**任务系统**

* FSM / 行为树框架
* 作业流程定义
* 异常处理逻辑（暂停 / 恢复 / 回退）

**作业机构**

* 清洁机构控制接口
* 作业参数调节
* 同步控制逻辑

### 输出成果

* 从基站出发
* 到达指定作业排
* 完成单排作业
* 自动返回

**阶段标志**

> 形成完整作业闭环。

---

## **P3 阶段：平台化与稳定性（7–12 个月）**

### 目标

从“能用”提升为“可长期运行”。

### 主要工作

**系统稳定性**

* 节点异常自动恢复
* 定位丢失降级策略
* 作业中断恢复机制

**工程化**

* rosbag 回放体系
* 参数在线调节
* 日志分析工具

**平台沉淀**

* 作业机构抽象接口
* 多产品适配能力
* 配置化部署体系

### 输出成果

* 连续多天稳定运行
* 多场地复现成功
* 可支撑新型号快速接入

**阶段标志**

> 系统具备平台价值。

---

## 四、阶段投入比例建议

| 阶段 | 人力投入占比 |
| -- | ------ |
| P0 | 10%    |
| P1 | 30%    |
| P2 | 35%    |
| P3 | 25%    |

说明：

* 前期以架构为主
* 中期以打通闭环为主
* 后期以稳定与复用为主

---

## 五、路线图总结

该路线图确保：

* 3 个月可展示样机
* 6 个月可完成真实作业
* 12 个月形成可复用平台

整体节奏可控，风险分散，成果清晰，适合作为公司新平台线的正式建设路径。
