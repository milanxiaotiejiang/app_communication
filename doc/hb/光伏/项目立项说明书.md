# 新一代机器人平台项目立项说明书

---

## 一、项目背景

当前行业机器人产品正逐步从“单一功能设备”向“平台型机器人系统”演进。
早期清洁机器人系统以室内环境为主，依赖 ROS1 架构，整体在稳定性与功能完整性方面已达到较成熟水平，但在以下方面逐渐显现局限：

* 架构老化，ROS1 已进入维护末期，生态演进基本停止
* 对室外、大尺度、强重复环境支持不足
* 系统扩展成本高，难以支撑新形态作业机器人（如光伏清洁、抛光、巡检等）
* 原系统工程结构偏产品化，不适合长期多产品复用

随着新公司业务方向转向**室外作业型机器人平台**，继续沿用旧系统将在架构层面形成长期技术负担，亟需构建一套面向未来的新一代机器人软件平台。

---

## 二、项目目标

建设一套**基于 ROS2 的新一代机器人平台系统**，具备以下核心能力：

* 面向室外大场景作业环境（光伏场地、园区、工业场所）
* 支持 GNSS / RTK + 局部 SLAM 的混合定位体系
* 支持底盘 + 作业机构（清洁、抛光、拖拽式机构等）协同工作
* 形成可长期演进、可复用、可扩展的软件平台能力
* 为后续多型号机器人产品提供统一技术底座

该项目目标不是快速复刻旧清洁机器人产品，而是构建**可持续发展的平台型系统能力**。

---

## 三、项目定位与原则

### 项目定位

* **新平台线、新系统、新架构**
* 不继承旧产品代码，仅继承成熟工程经验
* 以“长期维护 + 多产品复用”为设计前提

### 核心设计原则

* 架构优先于算法
* 稳定性优先于精度
* 工程可控优先于技术前沿
* 平台能力优先于单一产品功能

---

## 四、项目建设范围

本项目建设范围包括：

1. **机器人基础平台能力**

    * ROS2 系统架构
    * 中间件通信与节点规范
    * 日志、诊断、异常恢复机制

2. **定位与导航基础能力**

    * GNSS / RTK 接入
    * 局部 SLAM（短距离连续位姿估计）
    * 多源定位融合（robot_localization）

3. **作业执行能力**

    * 底盘运动控制
    * 通道级作业导航
    * 作业轨迹规划与执行

4. **产品扩展能力**

    * 作业机构抽象接口
    * 作业参数与策略管理
    * 多产品复用能力

---

## 五、阶段性建设目标

### 第一阶段（0–3 个月）

* 完成整体技术架构设计
* 确定硬件选型方案
* 建立 ROS2 基础工程框架
* 样机具备基础运动与定位能力

**阶段成果：机器人可稳定运行、可定位、可远程调试**

---

### 第二阶段（3–6 个月）

* 接入 GNSS / RTK
* 完成局部 SLAM 连续位姿估计
* 打通“基站 → 作业区域 → 作业通道”完整流程
* 实现基础作业流程闭环

**阶段成果：机器人可完成完整作业流程**

---

### 第三阶段（6–12 个月）

* 系统稳定性提升
* 异常工况覆盖（丢定位、信号异常、被困）
* 多场地验证
* 平台化接口沉淀

**阶段成果：平台可复用，可支撑下一代产品快速孵化**

---

## 六、人员投入建议

初期团队以“小而精”为原则：

| 角色       | 人数  | 主要职责         |
| -------- | --- | ------------ |
| 系统 / 平台  | 1   | 架构设计、ROS2 框架 |
| 定位 / 感知  | 1–2 | GNSS、SLAM、融合 |
| 导航 / 控制  | 1   | 底盘运动与作业导航    |
| 嵌入式 / 驱动 | 1–2 | 硬件接入与稳定性     |
| 测试 / 产品  | 1   | 场地验证与流程      |

**总人数：5–7 人可启动项目。**

---

## 七、主要风险与应对策略

| 风险          | 应对方案               |
| ----------- | ------------------ |
| 场地尺度大，地图难维护 | 不依赖全局高精地图          |
| 环境高度重复      | GNSS + 里程计 + 通道级定位 |
| 算力受限        | 采用轻量 SLAM 与规则优先    |
| RTK 不稳定     | 支持降级模式（通道计数、轨迹复现）  |

---

## 八、项目价值总结

通过本项目建设，公司将获得：

* 一套面向未来的机器人软件平台能力
* 降低后续产品开发周期与人力成本
* 支撑光伏清洁、工业清洁、巡检等多形态机器人
* 避免旧系统技术债在新业务中持续累积

该项目不仅是单一产品研发，更是公司机器人业务长期发展的技术基础工程。
