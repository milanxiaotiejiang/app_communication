## **光伏板清洁机器人作业全流程**

### **阶段 0️⃣ 基站准备**

1. 机器人在基站充电、初始化。
2. 系统加载全局航拍地图（板块排布模型）。
3. GNSS/RTK初始化，获取粗粒度全局坐标。
4. 任务规划：确定作业行序、清扫策略、起止位置。

---

### **阶段 1️⃣ 前往作业区（全局导航）**

1. 底盘依据**GNSS/RTK全局位姿**沿规划路径行驶。
2. 局部SLAM开启记录轨迹，用于全局修正。
3. 路径偏离较大时：

    * EKF融合GNSS与局部SLAM，修正底盘全局位置。
4. 到达作业区入口点（通道起点）。

---

### **阶段 2️⃣ 通道内作业准备**

1. 底盘进入光伏板间通道，开启局部导航：

    * 传感器识别通道边界，保持居中。
2. 机械臂末端对准第一块板：

    * 编码器定位末端位置
    * 弹性挂载吸收底盘微小误差
    * 可根据板几何模型进行微调

---

### **阶段 3️⃣ 作业执行循环**

1. **单行作业**：

    * 机械臂拖动清洁机构沿板面移动。
    * 局部SLAM记录底盘轨迹和机械臂末端轨迹。
    * 板计数或通道编号记录当前位置。

2. **作业闭环校正**：

    * EKF融合局部SLAM + GNSS + 板计数修正底盘全局位姿。
    * 弹性挂载吸收残余偏差。

3. **行结束**：

    * 机械臂回到初始位置。
    * 底盘移动到下一行起点。

4. **循环**：

    * 重复步骤 1–3，直到完成整个光伏阵列。

---

### **阶段 4️⃣ 作业完成与回基站**

1. 完成最后一行后，机械臂收回，清洁机构复位。
2. 底盘依据全局GNSS + 局部SLAM轨迹回到基站：

    * EKF持续融合保证全局位置准确。
3. 到达基站：

    * 停止作业、充电。
    * 作业轨迹、覆盖率、异常记录上传云端。

---

### **阶段 5️⃣ 数据记录与分析**

1. 完整轨迹记录：

    * 底盘位姿、机械臂末端位置、作业状态。
2. 作业覆盖率计算：

    * 板编号 / 板行数 + 轨迹记录。
3. 异常与偏差分析：

    * 提供下次优化依据。
4. 可选：与航拍全局地图匹配，更新全局偏差。

---

### **⚡ 技术关键点**

| 阶段    | 技术重点                     |
| ----- | ------------------------ |
| 出发前   | 全局地图加载，GNSS初始化，任务规划      |
| 前往作业区 | GNSS + 局部SLAM融合全局导航      |
| 通道内   | 局部导航保持通道中心，机械臂末端定位       |
| 作业循环  | 板计数辅助修正，EKF融合轨迹，弹性挂载吸收偏差 |
| 回基站   | 全局导航+轨迹闭环，保证安全返回         |
| 数据分析  | 作业轨迹、覆盖率、异常记录            |

---

> 总结：整体流程是**粗全局定位 → 局部闭环导航 → 机械臂作业 → 周期性修正 → 循环作业 → 回基站**，保证大面积覆盖且不依赖高计算量点云匹配。
