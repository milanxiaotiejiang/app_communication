# 视觉 SLAM（VSLAM）简介

## 一、核心概念

* **输入**：摄像头图像（单目、双目、RGB-D）

* **输出**：

    * 相机 / 机器人位姿
    * 环境地图（稀疏特征点云、稠密点云或网格地图）

* **目标**：同时**定位**和**建图**，类似传统 SLAM，但传感器是视觉而非激光雷达。

---

## 二、工作原理（简化工程版）

1. **特征提取**

    * 从图像中提取关键点（ORB、SIFT、SURF 等）
2. **特征匹配**

    * 相邻帧或关键帧之间匹配特征
3. **位姿估计**

    * 根据匹配特征求解相机位姿（PnP 或光束法平差 BA）
4. **地图更新**

    * 将新特征加入地图
5. **回环检测**

    * 识别已经走过的位置，优化全局地图

> 核心算法类似传统 SLAM，只是“传感器换成了摄像头”，算法多依赖图像处理、视觉几何和优化。

---

## 三、VSLAM 的特点

| 特点    | 描述                          |
|-------|-----------------------------|
| 传感器   | 单目 / 双目 / RGB-D 摄像头         |
| 成本    | 摄像头低于激光雷达，重量轻               |
| 算力    | 对 CPU / GPU 要求较高（特征提取 + BA） |
| 环境适应性 | 光线敏感，弱光或强光环境精度下降            |
| 地图类型  | 稀疏点云 / 特征点地图 / 稠密深度地图       |
| 精度    | 对小型移动机器人足够，但受光照、纹理影响大       |

---

## 四、与激光 SLAM 的对比

| 维度   | 2D 激光 SLAM | VSLAM           |
|------|------------|-----------------|
| 传感器  | 激光雷达       | 摄像头             |
| 算力需求 | 中低         | 高（GPU 或 CPU 密集） |
| 光照依赖 | 不敏感        | 强依赖环境光照和纹理      |
| 地图类型 | 2D 栅格地图    | 稀疏 / 稠密特征点云     |
| 成本   | 高（雷达贵）     | 低（摄像头便宜）        |
| 精度   | 高度稳定       | 光线好时高精度，光线差易漂移  |
