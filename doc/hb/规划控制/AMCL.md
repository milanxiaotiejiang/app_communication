## **一、AMCL 概述**

### 1️⃣ 定义

* **AMCL**：Adaptive Monte Carlo Localization，自适应粒子滤波定位算法
* **功能**：在**已知 2D 地图**上实时估计机器人位姿（`x, y, θ`）
* **核心思想**：

    1. 用 **粒子集合** 表示机器人在地图中的可能位置
    2. 根据传感器（激光雷达）与地图匹配更新粒子权重
    3. 根据里程计预测机器人运动
    4. 粒子重采样 → 保持定位稳定性

### 2️⃣ 输入

* 已知 2D 栅格地图（`map`）
* 里程计信息（`/odom`）
* 激光雷达扫描（`/scan`）

### 3️⃣ 输出

* 位姿估计（`geometry_msgs/PoseWithCovarianceStamped`）
* 发布 TF：`map → base_link`

### 4️⃣ 算法特点

| 特性     | 描述                  |
| ------ | ------------------- |
| 粒子滤波   | 通过 N 个粒子表示位姿概率分布    |
| 自适应粒子数 | 根据不确定性动态调整粒子数量      |
| 里程计预测  | 融合机器人运动信息，预测粒子移动    |
| 激光匹配修正 | 使用激光扫描与地图匹配更新粒子权重   |
| 抗干扰    | 粒子重采样 + 随机扩散可应对局部遮挡 |

## **二、AMCL 在 ROS2 的迁移**

### 1️⃣ ROS1 → ROS2 差异

| 方面    | ROS1 AMCL                                   | ROS2 AMCL                           |
| ----- | ------------------------------------------- | ----------------------------------- |
| 包名    | `amcl`                                      | `nav2_amcl`                         |
| 消息类型  | `sensor_msgs/LaserScan`、`nav_msgs/Odometry` | 相同，但使用 ROS2 消息和 QoS                 |
| TF 发布 | `tf`                                        | `tf2_ros`（map → base_link）          |
| 参数    | `yaml` 配置文件                                 | 类似，但支持 ROS2 launch / parameters API |

### 2️⃣ 核心迁移步骤

1. **地图准备**

    * 确保 `map_server` 发布 ROS2 树的 `/map`
    * 与 AMCL `map_frame` 对齐

2. **话题适配**

    * `/odom` → AMCL 里程计输入
    * `/scan` → 激光雷达扫描输入
    * 输出 `/amcl_pose` + TF `map → base_link`

3. **参数迁移**

    * 粒子数 (`min_particles` / `max_particles`)
    * 激光匹配权重 (`laser_z_hit`, `laser_sigma_hit`)
    * 里程计噪声 (`odom_alpha1~4`)
    * 全局重定位阈值 (`recovery_alpha`, `resample_interval`)

4. **Launch 文件**

    * 使用 ROS2 launch（Python / XML）启动 AMCL
    * 可同时启动 map_server + costmap + Nav2

## **三、AMCL 二次开发与优化方向**

### 1️⃣ 定位精度提升

* **粒子数优化**：动态调整粒子数量和分布
* **传感器融合**：IMU / 轮速计融合，提高旋转/滑动场景精度
* **多传感器权重**：激光 + 深度相机融合

### 2️⃣ 初始位姿与全局定位

* **自动初始化**：

    * 在未知初始位置时进行全局随机粒子初始化
* **全局重定位**：

    * 遇到被推离地图或被撞离位置时自动重置

### 3️⃣ 动态环境适应

* **动态障碍物过滤**：

    * 激光雷达扫描中忽略移动物体
* **粒子漂移修正**：

    * 融合局部地图子图或 SLAM 位姿

### 4️⃣ ROS2 集成优化

* QoS 调整 → 适应低频 / 丢帧传感器
* TF 校验 → 保证 `map → odom → base_link` 树稳定
* 日志 + 状态监控 → 便于长期运行（清扫机器人每日任务）

## **一、EKF / UKF 概述**

### 1️⃣ EKF（Extended Kalman Filter，扩展卡尔曼滤波）

* **类型**：递推式状态估计滤波器
* **用途**：在非线性系统中估计机器人位姿、速度、传感器偏差等
* **原理**：

    1. 系统状态方程非线性：( x_{k+1} = f(x_k, u_k) + w_k )
    2. 测量方程非线性：( z_k = h(x_k) + v_k )
    3. 对非线性函数 **一阶泰勒展开线性化** → 用标准 Kalman Filter 更新
* **优点**：

    * 算法成熟、计算量低
    * 可融合里程计、IMU、激光雷达等多源信息
* **缺点**：

    * 对线性化近似敏感
    * 强非线性或高噪声场景精度下降

---

### 2️⃣ UKF（Unscented Kalman Filter，无迹卡尔曼滤波）

* **类型**：非线性状态滤波器
* **原理**：

    * 通过 **Unscented Transform** 选取一组 sigma points
    * 对状态分布传播非线性系统 → 精确捕获均值和协方差
* **优点**：

    * 精度比 EKF 高，非线性鲁棒性好
    * 不需要求导，适合复杂非线性系统
* **缺点**：

    * 计算量高于 EKF
    * 实时性要求高时需优化

---

## **二、多传感器融合示例（室内清洁机器人）**

| 传感器       | 作用        | EKF/UKF 融合方式                 |
| --------- | --------- | ---------------------------- |
| 里程计       | 机器人运动预测   | 预测状态 (x_{k+1} = f(x_k, u_k)) |
| IMU       | 角速度、加速度补偿 | 提供旋转/加速度约束                   |
| 激光雷达      | 位姿校正      | 更新状态，减少漂移                    |
| VSLAM（可选） | 位姿/增量地图   | 观测更新，提高精度                    |

## **三、插值和平滑**

### 1️⃣ 插值

* **目的**：处理传感器不同频率导致的时间不对齐
* **方法**：

    * **线性插值**：适合里程计/IMU 简单位姿数据
    * **多项式 / Cubic Spline 插值**：更平滑
* **作用**：

    * 保证 EKF / UKF 输入的同步性
    * 减少因丢帧或延迟导致的滤波误差

### 2️⃣ 平滑（后端滤波 / smoothing）

* **目的**：提高历史轨迹精度
* **方法**：

    * **Rauch–Tung–Striebel (RTS) 平滑** → 后向修正
    * **滑动窗口优化** → 近似 BA
* **作用**：

    * 修正漂移和异常测量
    * 对轨迹重建和地图优化有帮助

## **四、EKF / UKF 后续开发方向**

### 1️⃣ 工程化改进

* **自适应噪声估计**：根据传感器状态动态调整噪声矩阵
* **状态扩展**：加入轮滑检测、激光遮挡标志位、IMU 偏置
* **多速率处理**：里程计 50Hz，IMU 200Hz，激光 10Hz → 插值同步

### 2️⃣ 与 SLAM / AMCL 集成

* EKF / UKF 输出可作为：

    * SLAM 初始位姿
    * AMCL 粒子滤波预测
* 提高定位稳定性和鲁棒性

### 3️⃣ 异常检测

* 利用 EKF / UKF **残差**判断传感器异常
* 异常处理策略：

    * 剔除异常观测
    * 减小权重
    * 临时切换传感器

### 4️⃣ 长期运行优化

* 滑动窗口滤波 + 平滑
* 与 Nav2 / SLAM Toolbox 联动，保证 map → base_link TF 连续

---

## **五、工程实践总结**

1. **EKF**：

    * 适合算力有限、线性或弱非线性系统
    * 可实时融合 IMU + 里程计 + 激光位姿

2. **UKF**：

    * 非线性强、动态环境多
    * 精度高，但算力要求高

3. **插值与平滑**：

    * 保证不同传感器时间同步
    * 修正漂移，优化轨迹

4. **二次开发重点**：

    * 噪声自适应
    * 异常检测与剔除
    * 滑动窗口或后向平滑优化
    * 与 SLAM / Nav2 接口融合
