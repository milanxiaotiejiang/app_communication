# 🔷 一、全局规划（Global Planner）调优重点

Nav2 默认的全局规划来自 **NavFn** 或 **Smac planners**（Hybrid-A*、A* 等）。

清洁机器人常用的是 **Hybrid-A***（适应非完整约束），所以我以它为主讲。

---

# ✔ 1) 全局规划曲线不自然 / 轨迹不平滑

**原因：**

* 纯 A* 只关心最短路径，不关心曲率
* 生成的路径尖锐、折线多
* 清洁机器人（差速轮）无法直接跟踪

**调优方向：**

| 参数方向  | 配置项                       | 作用         |
| ----- | ------------------------- | ---------- |
| 平滑程度  | `smoother.smoothness`     | 越大越平滑，但更绕路 |
| 曲率限制  | `smoother.max_curvature`  | 限制路径转弯强度   |
| 近目标优化 | `smoother.goal_tolerance` | 避免最后阶段震荡规划 |

**典型做法：**

* 降低 “最短路径权重”
* 提高 “曲率连续性” 权重
* 允许路径稍微长一点来换稳定性

---

# ✔ 2) 全局路径穿过障碍物（或太靠近障碍）

常见原因：

* costmap 分辨率太大（>5cm）
* footprint 配置不准确
* 膨胀系数设置不合理

**调优方向：**

| 参数                    | 典型值       | 说明              |
| --------------------- | --------- | --------------- |
| `inflation_radius`    | 0.6–1.2m  | 必须>机器人直径，否则贴墙太近 |
| `cost_scaling_factor` | 5–10      | 越大越“远离”障碍物      |
| `resolution`          | 0.03–0.05 | 清洁机器人一般取 3–5 cm |

**实战秘诀：**

* 障碍膨胀圈要**比机器人宽 20–30cm**
* 机器人 footprint 一定要用动态加载真实外形，而非矩形粗略值

---

# ✔ 3) 可行区域被割裂 / 无法规划

典型原因：

* 地毯反光 / 某些障碍物反复出现消失
* obstacle layer 错误地清除 or 累计障碍
* laser scan 滤波不良，出现虚假障碍

**解决方式：**

1. **调整障碍物衰减时间**

   ```
   observation_persistence: 0.0 → 2.0
   ```

   让障碍物稍微保持一段时间，不要闪烁造成地图不连通。

2. **使用 voxel layer 或 pointcloud layer**
   增强高度信息，使误障碍减少。

3. **给全局规划切换到 coarse costmap**
   仅在大范围规划时使用粗粒度地图

    * 全局 costmap: resolution=0.05~0.10
    * 局部 costmap: resolution=0.02~0.05

➡ 能显著减少“无路径”问题。
