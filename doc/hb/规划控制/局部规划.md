# 🔷 二、局部规划（Local Planner）调优重点

Nav2 常用局部规划器：

* **DWB**（默认）
* **TEB**（时间弹性带）
* **MPC Controller**（强化动力学约束）

我按实际调参难度从易到难说明。

---

# ⭐ 1) DWB（Dynamical Window Approach）

## ✔ DWB 的典型问题：

1. **抖动**（在窄通道左右抖）
2. **无法贴墙**（清洁机器人需要靠边行走）
3. **转弯不够平滑**
4. **避障不自然 / 吃 CPU**

---

## ✔ 关键调优参数：

### 🔹 1. 采样数量（控制精度 vs 性能）

```
vx_samples: 20
vy_samples: 5
vth_samples: 40
```

清洁机器人通常需要较高的 `vth_samples` 来产生更细腻的角度选择。

---

### 🔹 2. 速度限制

```
max_vel_x
min_vel_x
max_vel_theta
max_acc_x
max_acc_theta
```

要与底盘控制器实际能力一致，否则会震荡。

---

### 🔹 3. 代价权重调节

```
PathAlignWeight
GoalAlignWeight
ObstacleWeight
```

✔ 清洁机器人需要：

* 强化 `ObstacleWeight`
* 降低 `PathAlignWeight`：避免死命贴着全局路径走

📌 常见策略：

```
ObstacleWeight: 5.0
PathAlignWeight: 1.0
GoalAlignWeight: 0.5
```

这样机器人能主动让路，也更少卡死。

---

# ⭐ 2) TEB（Time Elastic Band）

TEB 是强大但难调的规划器，适用狭窄场景。

---

## ✔ TEB 常见问题：

1. **在狭窄通道中震荡**
2. **规划时间过长**
3. **过度靠墙或卡死**
4. **急转弯时速度指令不稳定**

---

## ✔ 调优方向：

### 🔹 1. 时间解析度

```
dt_ref
dt_hysteresis
```

越小越精细，但 CPU 占用爆炸。

---

### 🔹 2. 轨迹优化权重

```
weight_kinematics_nh
weight_optimaltime
weight_obstacle
weight_inflation
weight_velocity
```

关键点：

* 清洁机器人要贴墙，但不能碰：
  `weight_obstacle` 不能太小
* 想要更平滑的路径：
  `weight_velocity` / `weight_acc` 要提高

---

### 🔹 3. 机器人模型约束

```
max_vel_x
max_vel_theta
acc_lim_x
acc_lim_theta
min_turning_radius
```

如果**底盘实际性能与这里配置不符**，TEB 一定震荡。

---

### 🔹 4. 每个障碍物的膨胀和最小距离

```
min_obstacle_dist
inflation_dist
obstacle_association_force
```

清洁机器人常用参数：

```
min_obstacle_dist: 0.20
inflation_dist: 0.35
```

比机器人实际宽度多 10cm 是经验值。

---

# ⭐ 3) MPC（Model Predictive Control）

MPC 是未来趋势，适合高动态平台，但调参最难。

---

## ✔ MPC 常见问题：

1. **模型与实际动力学不一致 → 抖动**
2. **求解器时间超时 → 控制失效**
3. **权重配置不当 → 轨迹奇怪**
4. **跟踪误差累积**

---

## ✔ 调优方向：

### 🔹 1. 模型参数要准确

```
wheel_base
mass
moment_of_inertia
max_steer_rate
```

不准就会出现路径偏离和振荡。

---

### 🔹 2. 代价项权重

```
w_tracking_error
w_control_effort
w_smoothness
```

常见策略：

* 在走廊中提高 `tracking error`
* 在贴墙/贴边清洁时提高 `smoothness`，减少激烈加速

---

### 🔹 3. 求解器时间限制

```
max_solver_time
horizon
dt
```

时间越小越快但越不稳定；
商用机器人一般采用 `horizon=20~30`，`dt=0.1`。
