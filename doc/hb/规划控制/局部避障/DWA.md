## 1️⃣ DWA 的基本概念

**全名**：Dynamic Window Approach
**核心目标**：在局部环境中选择一条安全、可行、平滑的速度轨迹，使机器人朝向目标前进，同时避开障碍物。

它属于 **局部路径规划（Local Planner）**，通常在已有全局路径的情况下使用（例如 Nav2 的 Local Planner 插件）。

---

### 1.1 输入

* **当前机器人状态**：

    * 位置 `(x, y)`、航向 `θ`
    * 速度 `(v, ω)` — 线速度和角速度
* **全局目标 / 全局路径**
* **局部障碍物信息**：

    * 来自 Lidar、Depth Camera 等，通常转换为局部 costmap
* **机器人运动约束**：

    * 最大线速度、最大角速度
    * 最大加速度、角加速度

---

### 1.2 核心思想

DWA 的主要思路是：

1. **速度采样**：

    * 在可达的速度空间中生成一系列候选 `(v, ω)` 对
    * 速度空间限制：

        * 物理限制（最大速度、最大角速度）
        * 动力学限制（加速度/角加速度）
        * 安全约束（避开障碍）

2. **轨迹模拟**：

    * 对每个 `(v, ω)`，在短时间窗口内模拟机器人运动的轨迹（通常几百毫秒到 1 秒）
    * 预测轨迹在局部地图上是否碰撞

3. **轨迹评价**：

    * 每条轨迹计算评分函数，通常包括：

        * **前进目标方向评分**：离全局路径/目标越近越好
        * **速度评分**：鼓励高速移动
        * **安全评分**：距离障碍物越远越好
    * 总分最高的 `(v, ω)` 被选中

4. **速度输出**：

    * 将最佳 `(v, ω)` 发给机器人底盘 `/cmd_vel`

---

### 1.3 优点

* 反应快，适合动态环境（动态障碍物）
* 考虑运动学约束，生成可执行轨迹
* 可以和全局规划结合（跟随全局路径）

---

### 1.4 缺点

* 局部最优，可能陷入局部死角
* 对复杂几何环境可能无法规划最优路径
* 需要调参：

    * 速度采样步长
    * 时间窗口
    * 权重函数（速度 vs 安全 vs 距离目标）

---

### 1.5 在 ROS2 Nav2 中的应用

* Nav2 内置 **DWB（Dynamic Window Based local planner）**，就是 DWA 的升级版本

    * DWB = DWA + 更丰富的代价函数
    * 支持多层 Costmap（低矮障碍、悬崖、动态障碍）

* 典型数据流：

  ```
  /odom + /cmd_vel --> DWB_Local_Planner --> /cmd_vel
  /scan / costmap --> DWB_Local_Planner
  /global_path --> DWB_Local_Planner (作为前进目标参考)
  ```

* 参数主要调优：

    * `vx_samples`, `vtheta_samples`（速度采样点数）
    * `sim_time`（模拟时间窗口）
    * `acc_lim_x`, `acc_lim_theta`（加速度限制）
    * 权重：

        * `path_distance_bias`（贴近全局路径）
        * `goal_distance_bias`（朝向目标）
        * `occdist_scale`（障碍物安全距离）

---

### 1.6 总结

| 特点 | 说明                       |
| -- | ------------------------ |
| 类型 | 局部规划 / 运动控制              |
| 输入 | 当前位姿、速度、局部障碍物、全局路径       |
| 输出 | 最优速度 `(v, ω)`            |
| 核心 | 速度采样 → 模拟轨迹 → 评价函数 → 选最优 |
| 优点 | 快速、可执行、避障能力强             |
| 缺点 | 局部最优、依赖参数                |
