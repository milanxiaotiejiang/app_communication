## 1️⃣ TEB 基本概念

**全名**：Timed Elastic Band
**核心目标**：在局部路径规划时，生成一条 **平滑、可执行、时间优化的轨迹**，同时避开障碍物并满足机器人动力学约束。

它在 ROS 中常用作 **Local Planner Plugin**，尤其适合 **差分驱动和移动小车**，对路径平滑要求高的清洁、送货等应用很合适。

---

## 2️⃣ 输入

* **全局路径 / 目标点**
* **当前机器人位姿 `(x, y, θ)`**
* **当前速度 `(v, ω)`**
* **局部障碍物信息**（Costmap、Lidar、Depth Camera）
* **机器人运动学约束**：

    * 最大速度、最大加速度
    * 最大角速度、角加速度
* **优化权重参数**：

    * 平滑性、速度、障碍物距离等

---

## 3️⃣ 核心思想

### 3.1 Elastic Band

* 将全局路径转化为 **一系列离散的姿态点（pose）**，类似弹性带（Elastic Band）
* 每个点之间有距离约束
* 弹性带可以自由拉伸、压缩，优化后保持平滑性

### 3.2 时间约束（Timed）

* 为每个点分配一个时间间隔 Δt
* 可以优化 **机器人运动时间**，考虑加速度限制
* 这样每个点不仅有位置约束，还有速度约束 → 可直接生成速度指令

### 3.3 优化方法

* 将弹性带表示为 **优化问题**：

    * 目标函数：

        * 保持与全局路径接近
        * 保持轨迹平滑（最小曲率变化）
        * 避开障碍物（安全距离惩罚）
        * 满足时间 / 动力学约束
* 使用 **非线性优化器（如 g2o / Ceres）** 求解
* 输出：

    * 优化后的轨迹
    * 每个时间步对应的速度 `(v, ω)` → 直接下发 `/cmd_vel`

---

## 4️⃣ TEB vs DWA

| 特性    | DWA           | TEB                 |
| ----- | ------------- | ------------------- |
| 核心思想  | 速度采样 + 模拟轨迹   | 弹性带优化 + 时间约束        |
| 轨迹平滑性 | 中等            | 高（优化连续轨迹）           |
| 速度控制  | 输出瞬时 `(v, ω)` | 输出连续轨迹 + `(v, ω)`   |
| 避障    | 快速、局部反应       | 快速 + 考虑平滑性          |
| 适用场景  | 动态环境          | 需要平滑轨迹、高精度清洁/送货     |
| 参数调节  | 采样点数、模拟时间、权重  | 权重、轨迹点间距、障碍物距离、安全边界 |

---

## 5️⃣ ROS2 Nav2 中 TEB

* Nav2 内置 **TEB Local Planner Plugin**：

    * 输入：

        * `/odom`、`/scan`、局部 costmap
        * `/global_path`
    * 输出：

        * `/cmd_vel`
* 可调参数：

    * `teb_local_planner/weight_...`（不同优化权重）
    * `teb_local_planner/max_vel_x`, `max_vel_theta`
    * `teb_local_planner/horizon`（预测步数 / 弹性带长度）
    * `obstacle_...`（障碍物处理、最小距离）

---

### 6️⃣ 总结

* **DWA**：速度采样，快速反应，适合动态障碍物；局部轨迹平滑性一般。
* **TEB**：优化弹性带 + 时间约束，轨迹平滑、动力学约束可控；适合清洁机器人等对轨迹平滑要求高的场景。
* **MPC**：更通用的最优控制方法，可同时考虑轨迹平滑 + 动力学约束 + 优化目标，计算量较大。
