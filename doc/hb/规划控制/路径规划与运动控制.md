# 一、全局规划（Global Planning）

| 方案                                  | 核心原理                           | 优点             | 缺点       | 推荐场景          |
| ----------------------------------- | ------------------------------ | -------------- | -------- | ------------- |
| **A* / Dijkstra**                   | 栅格地图最短路径搜索                     | 简单、稳定          | 粗糙路径，不平滑 | MVP、早期验证      |
| **NavFn / DWA 原生 global planner**   | 基于 costmap                     | ROS1/ROS2 可直接用 | 路径平滑有限   | 中小型室内环境       |
| **Coverage Path Planning (CPP)**    | 蚂蚁算法 / Zig-Zag / Boustrophedon | 专门覆盖地面         | 算法复杂，需地图 | 清洁覆盖型机器人，工业场景 |
| **Spline / Bezier / Clothoid 轨迹生成** | 稀疏路径插值为平滑曲线                    | 平滑，适合 MPC      | 需要曲线库    | 商用轨迹平滑追踪      |
| **Hybrid A* / RRT***                | 栅格+曲线生成                        | 支持弯道           | 计算量大     | 高自由度/复杂室内环境   |

**落地建议**：

* 清洁机器人多数是**覆盖型**，用 **CPP → Spline 平滑** + **MPC** 足够
* 先用简单 A* 或 Zig-Zag 做 MVP

# 二、局部规划 / 避障（Local Planning）

| 方案                                | 核心原理                          | 优点           | 缺点        | 推荐场景        |
| --------------------------------- | ----------------------------- | ------------ | --------- | ----------- |
| **DWA (Dynamic Window Approach)** | 采样速度空间 + 代价函数                 | 快速，ROS1/2 内置 | 对曲线路径平滑不好 | 快速避障原型      |
| **TEB (Timed Elastic Band)**      | 将路径建成带时间的弹性曲线                 | 平滑，考虑动力学     | 对障碍密集区需调参 | 小车/差速车，工业清洁 |
| **局部 MPC（带约束）**                   | 将障碍约束放入 MPC cost / constraint | 平滑、可预测       | 计算量大      | 高端商用，可选     |
| **速度/轨迹偏移 + MPC**                 | MPC 不直接看障碍，通过轨迹偏移避障           | 简单、快速        | 难处理动态障碍   | 商用清洁机器人首选   |

**落地建议**：

* **快速落地** → 使用 **轨迹偏移 + MPC**
* **中长期升级** → 内置障碍约束 NMPC

# 三、运动控制（Motion Control / Tracking）

| 方案                          | 核心原理        | 优点       | 缺点           | 推荐场景        |
| --------------------------- | ----------- | -------- | ------------ | ----------- |
| **PID / Pure Pursuit**      | 简单闭环        | 实现快      | 路径抖动明显，转弯不平滑 | MVP，验证机器人运动 |
| **Stanley Controller**      | 横向误差 + 航向误差 | 转弯平滑     | 高速下可能振荡      | 差速机器人       |
| **DWA 控制器**                 | 动态窗口采样速度    | 避障实时性好   | 平滑性一般        | 避障原型        |
| **TEB Controller**          | 时间弹性带优化     | 路径平滑、可避障 | 算复杂         | 小车/工业清洁     |
| **MPC（Linear / Nonlinear）** | 预测状态 + 优化控制 | 平滑、可加约束  | 求解器依赖        | 商用轨迹控制首选    |

**落地建议**：

* **商用清洁机器人重点** → MPC（差速车模型）
* 可以结合轨迹平滑 spline + MPC，控制器输出 `(v, w)`
* 避障时只修改 **参考轨迹 + v_ref** 即可快速落地

# 四、推荐整体架构（落地 + 可扩展）

```
[全局路径规划]          -> A*/CPP -> Spline/Bezier 平滑
           ↓
[局部路径/避障]          -> 局部 costmap + 轨迹偏移 + v_ref 调整
           ↓
[运动控制器]            -> MPC (差速模型, dt=0.1s, N=10~15)
           ↓
[底盘接口]              -> 发送 Twist 或底盘速度命令
           ↓
[传感器反馈]            -> Odom + Laser/Camera
           ↺
```

* **MVP**：A* + PID 或 Pure Pursuit + 局部速度调节避障
* **商用稳定**：CPP/Zig-Zag + Spline + MPC + 局部轨迹偏移避障
* **高端版本**：CPP + TEB/NMPC（内置障碍约束） + MPC 轨迹跟踪 + 动态障碍处理
