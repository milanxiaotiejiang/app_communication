**详细说明**：
```
建图过程中想使用上一份地图，请求流程：end_map（save传false）->work_to_enter
正常保存地图：end_map（save传true）->work_to_enter
score：评分，0-1.0，甚至1.0以上，一般是0.7-0.8，0.5就不行。
不管score值是多少，都会保存地图，这个值是保存地图以后算出来的
```
