在 C++ 中，`::` 被称为**范围解析运算符（scope resolution operator）**，用于**访问某个作用域中的名字**，明确作用域层级或全局符号。

---

### 1. 访问全局作用域

```cpp
int x = 10;

void func() {
    int x = 20;
    std::cout << ::x << std::endl; // 访问全局 x = 10
}
```

---

### 2. 访问类的静态成员

```cpp
class A {
public:
    static int count;
};

int A::count = 0;

void foo() {
    A::count = 5; // 通过类名访问静态成员
}
```

---

### 3. 访问命名空间成员

```cpp
namespace NS {
    int val = 100;
}

int main() {
    std::cout << NS::val << std::endl; // 访问命名空间成员
}
```

---

### 4. 定义类外的成员函数

```cpp
class A {
public:
    void show();
};

void A::show() {
    std::cout << "Hello" << std::endl;
}
```

* 明确成员函数属于哪个类
* 在类外实现成员函数时必用

---

### 5. 与 `typedef` / 嵌套类型结合

```cpp
class Outer {
public:
    class Inner {};
};

Outer::Inner obj; // 访问嵌套类型
```

---

### 6. 特殊用法

* `::` 单独写 → 指全局作用域
* `类名::成员名` → 静态成员或嵌套类型
* `命名空间::名字` → 访问命名空间成员

---

### 7. 小提示

* 可与模板、命名空间嵌套结合使用
* 常用于**消除二义性或访问隐藏名字**

---

### 一句话总结

> `::` 是**指明名字所属范围的标志**，
> 让编译器知道从哪个作用域获取符号，避免歧义。
