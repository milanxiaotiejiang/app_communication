在 C++ 中，**引用（reference）**是一种**已命名的别名**，允许通过另一个名字访问同一个对象。引用本质上是一个**对象的别名，而不是独立的存储单元**。

---

### 1. 基本语法

```cpp
int a = 10;
int& ref = a;  // ref 是 a 的引用
ref = 20;      // a 也变为 20
```

* 必须在定义时初始化
* 一旦绑定，无法更改引用目标

---

### 2. 与指针的区别

| 特性      | 引用    | 指针            |
| ------- | ----- | ------------- |
| 是否必须初始化 | 是     | 否             |
| 可否重新绑定  | 否     | 是             |
| 是否为空    | 否     | 可为 nullptr    |
| 访问语法    | 像普通变量 | 使用 `*` 或 `->` |
| 内存开销    | 无额外开销 | 占用指针大小        |

---

### 3. 引用类型

#### 3.1 左值引用（Lvalue Reference）

```cpp
int a = 1;
int& r = a;  // 左值引用
```

#### 3.2 右值引用（Rvalue Reference，C++11）

```cpp
int&& r = 5; // 右值引用
```

* 可绑定临时对象
* 支持 **移动语义** 与 **完美转发**

---

### 4. 常量引用

```cpp
const int& r = a;
```

* 可以绑定左值或右值
* 内部不可修改原对象
* 常用于函数参数，避免拷贝：

```cpp
void foo(const std::string& s);
```

---

### 5. 引用作为函数返回值

#### 5.1 返回左值引用（允许修改外部对象）

```cpp
int& get(int& x) { return x; }
```

#### 5.2 返回右值引用（移动语义）

```cpp
std::string&& makeString() { return std::move(temp); }
```

---

### 6. 引用的典型应用

* 函数参数传递（避免拷贝，提高效率）
* 操作符重载（如 `operator[]`）
* 链式调用（返回引用）
* 支持移动语义与完美转发（C++11 及以后）

---

### 7. 注意事项

* 不可创建空引用
* 不可修改绑定对象（除非非 const 引用）
* 返回局部变量引用会导致悬空引用

---

### 一句话总结

> 引用是**对象的别名**，提供高效、直观的访问方式，
> 在函数参数、返回值以及移动语义中扮演核心角色。
