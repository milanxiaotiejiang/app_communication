**封装（Encapsulation）** 是面向对象编程的核心概念之一，指将**数据（成员变量）和操作数据的方法（成员函数）组合在一个类内部**，并通过访问控制来隐藏内部实现细节，从而提供安全、可控的接口。

---

### 1. 访问控制

C++ 提供三种访问权限：

| 访问权限        | 描述            | 外部访问      |
| ----------- | ------------- | --------- |
| `private`   | 私有成员，仅类内部可访问  | ❌         |
| `protected` | 受保护成员，类及子类可访问 | ❌（外部不可访问） |
| `public`    | 公共成员，任何地方可访问  | ✔         |

---

### 2. 基本示例

```cpp
class Account {
private:
    double balance; // 私有数据
public:
    void deposit(double amt) { balance += amt; } // 公共接口
    void withdraw(double amt) {
        if (amt <= balance)
            balance -= amt;
    }
    double getBalance() const { return balance; }
};
```

* 外部无法直接修改 `balance`
* 必须通过 `deposit` / `withdraw` 控制操作
* 保证数据安全和不变量成立

---

### 3. 封装的优势

1. **数据保护**：防止外部非法访问或修改
2. **接口与实现分离**：修改内部实现不会影响外部使用
3. **提高可维护性**：内部逻辑隐藏，外部只依赖接口
4. **增强代码复用**：类成为可独立使用的模块

---

### 4. 结合实际场景

* **嵌入式设备**：传感器对象只暴露读取/配置接口，不允许直接修改寄存器值
* **金融系统**：账户余额通过方法控制，保证业务逻辑正确
* **机器人控制**：移动模块封装速度与方向，外部只能通过控制接口下达命令

---

### 一句话总结

> 封装就是**将数据与操作组合并隐藏实现细节**，
> 通过受控接口保护对象状态，保证安全性和可维护性。
