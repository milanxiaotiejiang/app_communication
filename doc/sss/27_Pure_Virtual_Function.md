**纯虚函数（Pure Virtual Function）** 是 C++ 中用于**定义接口规范而不提供具体实现**的虚函数。它是实现抽象类和多态的基础。

---

### 1. 定义语法

```cpp
class Shape {
public:
    virtual void draw() = 0; // 纯虚函数
};
```

* `= 0` 表示函数没有实现
* 类中至少有一个纯虚函数 → **抽象类**
* 抽象类不能实例化，只能被继承

---

### 2. 派生类实现

```cpp
class Circle : public Shape {
public:
    void draw() override { std::cout << "Draw Circle\n"; }
};

Shape* s = new Circle();
s->draw(); // 调用 Circle 的 draw()
```

* 派生类必须实现纯虚函数，才能实例化对象
* 支持**运行时多态**

---

### 3. 特点

1. 定义接口而不实现功能
2. 强制子类提供具体实现
3. 可以和普通成员函数共存
4. 支持多态调用

---

### 4. 抽象类示例

```cpp
class Animal {
public:
    virtual void speak() = 0; // 纯虚函数
    void eat() { std::cout << "Eating\n"; } // 普通成员函数
};
```

* 抽象类可以包含普通函数
* 子类必须实现纯虚函数 `speak()`

---

### 5. 使用场景

* **接口设计**：定义统一接口，不关心具体实现
* **多态容器**：基类指针操作多种派生类对象
* **模块化系统**：不同模块实现统一方法

```cpp
class RobotModule {
public:
    virtual void run() = 0; // 不同模块实现不同运行逻辑
};
```

---

### 6. 注意事项

* 抽象类不能实例化
* 派生类必须实现所有纯虚函数，除非自己也作为抽象类
* 析构函数也可声明为纯虚函数，但仍需提供实现以保证对象正确销毁

---

### 一句话总结

> 纯虚函数是**只声明接口、不提供实现的虚函数**，
> 强制派生类实现功能，是抽象类和运行时多态的核心工具。
