在 C++ 中，**接口（Interface）** 通常指一组**纯虚函数的集合**，用于规定类必须实现的行为规范，而不包含具体实现。接口本质上是一种抽象类的形式，用于实现**多态和模块化设计**。

---

### 1. 定义接口

```cpp
class IShape {
public:
    virtual void draw() = 0;       // 纯虚函数
    virtual double area() = 0;     // 纯虚函数
    virtual ~IShape() = default;   // 虚析构函数
};
```

* `= 0` 表示纯虚函数
* 虚析构函数确保通过基类指针删除派生类对象时正确释放资源

---

### 2. 实现接口

```cpp
class Circle : public IShape {
    double radius;
public:
    Circle(double r) : radius(r) {}
    void draw() override { /* 绘制圆 */ }
    double area() override { return 3.14159 * radius * radius; }
};

IShape* s = new Circle(5.0);
s->draw();
delete s;
```

* 派生类必须实现所有纯虚函数
* 可以通过基类指针统一调用接口方法

---

### 3. 特点

1. **只声明行为，不提供实现**
2. **支持运行时多态**
3. **不能实例化**
4. 用于约束派生类的行为规范

---

### 4. 优势

* **解耦**：调用者只依赖接口，不依赖具体实现
* **可扩展**：新增实现无需修改调用代码
* **统一管理**：多个不同实现可以通过同一接口操作

---

### 5. 使用场景

* **机器人控制**：定义移动、旋转接口，不同机器人实现不同逻辑
* **GUI 系统**：统一控件接口（绘制、事件响应）
* **嵌入式驱动**：定义传感器接口，各类传感器实现具体读数

---

### 一句话总结

> 接口是 **只定义行为规范的抽象类**，
> 用于实现多态、模块化和代码解耦，使不同实现可统一操作。
