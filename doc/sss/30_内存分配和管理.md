在 C++ 中，**内存分配和管理**是程序设计的重要组成部分，涉及如何为变量、对象和数据结构分配内存、访问它们，以及在不需要时释放内存。C++ 提供了 **静态内存、栈内存和堆内存** 三种管理方式，并允许开发者通过操作符和智能指针控制内存。

---

### 1. 内存类型

| 类型       | 分配方式    | 生命周期     | 示例                       |
| -------- | ------- | -------- | ------------------------ |
| **静态内存** | 编译时确定   | 程序全局存在   | 全局变量、静态变量                |
| **栈内存**  | 函数调用时分配 | 函数退出自动释放 | 局部变量、函数参数                |
| **堆内存**  | 运行时动态分配 | 手动释放     | `new` / `delete` 或智能指针管理 |

---

### 2. 栈内存

* **自动分配**，速度快
* 生命周期由作用域控制
* 不需要手动释放

```cpp
void foo() {
    int x = 10;   // 栈上分配
} // x 出作用域自动释放
```

---

### 3. 堆内存（动态内存）

* 由程序员手动控制
* 通过 `new` / `delete` 分配与释放

```cpp
int* p = new int(5); // 动态分配
delete p;            // 释放内存

int* arr = new int[10]; 
delete[] arr;        // 释放数组内存
```

* 不释放会导致 **内存泄漏**
* 多次释放同一内存会导致 **悬空指针**

---

### 4. 智能指针（C++11）

* **自动管理动态内存**，防止泄漏
* 常用类型：

    * `std::unique_ptr`：独占所有权
    * `std::shared_ptr`：共享所有权，引用计数
    * `std::weak_ptr`：辅助 `shared_ptr` 避免循环引用

```cpp
#include <memory>
std::unique_ptr<int> up = std::make_unique<int>(10);
```

---

### 5. 内存管理注意事项

1. 动态分配要对应释放
2. 尽量使用智能指针代替裸指针
3. 避免悬空指针和野指针
4. 注意对象生命周期与指针作用域
5. 避免内存碎片和过度频繁的分配释放

---

### 6. 小结

* **栈内存**：自动管理，效率高，适合小对象
* **堆内存**：手动管理，适合大对象和动态需求
* **智能指针**：现代 C++ 推荐方式，安全高效
* **静态内存**：程序全局存在，生命周期与程序一致

---

### 一句话总结

> 内存分配和管理是 C++ 的核心能力，
> 栈内存自动管理、堆内存动态管理，而智能指针提供安全的自动释放机制，确保资源高效与安全使用。
