在 C++ 中，智能指针是一种 **RAII（资源获取即初始化）机制**，用于管理动态分配的内存，避免内存泄漏和悬空指针。C++11 引入了 `shared_ptr`、`unique_ptr` 和 `weak_ptr`，而 `auto_ptr` 是 C++98/03 的旧式智能指针，已被弃用。

---

### 1. `unique_ptr`

* **独占所有权**：一个对象只能被一个 `unique_ptr` 管理
* 不可复制，但可以移动（支持移动语义）
* 自动释放对象，无需手动 `delete`

```cpp
#include <memory>

std::unique_ptr<int> uptr = std::make_unique<int>(10);
// std::unique_ptr<int> up2 = uptr; // ❌ 编译错误
std::unique_ptr<int> up2 = std::move(uptr); // ✅ 转移所有权
```

**使用场景**：管理独占资源，如单个对象、文件句柄、嵌入式硬件对象。

---

### 2. `shared_ptr`

* **共享所有权**：多个 `shared_ptr` 可以指向同一对象
* 内部使用引用计数，最后一个 `shared_ptr` 被销毁时释放资源
* 可与 `weak_ptr` 搭配避免循环引用

```cpp
#include <memory>

std::shared_ptr<int> sp1 = std::make_shared<int>(20);
std::shared_ptr<int> sp2 = sp1; // 引用计数增加
```

**使用场景**：多个对象或模块共享同一资源，如缓存、共享数据结构。

---

### 3. `weak_ptr`

* 不拥有对象，不增加引用计数
* 用于观察由 `shared_ptr` 管理的对象
* 避免循环引用

```cpp
std::weak_ptr<int> wp = sp1;
if (auto spt = wp.lock()) { // 转换为 shared_ptr 使用
    // 对象存在，可访问
}
```

**使用场景**：观察对象状态，辅助 `shared_ptr` 避免循环引用，如双向链表、父子关系对象。

---

### 4. `auto_ptr`（已废弃）

* C++98/03 提供的智能指针
* 独占所有权，但**复制操作会转移所有权**（导致潜在悬空）
* C++11 起被 `unique_ptr` 替代

```cpp
#include <memory>

std::auto_ptr<int> ap(new int(30));
std::auto_ptr<int> ap2 = ap; // 所有权转移，ap 为空
```

**注意**：不推荐使用，现代 C++ 应用 `unique_ptr` 替代。

---

### 5. 总结对比

| 智能指针         | 所有权     | 可复制      | 引用计数 | 使用场景              |
| ------------ | ------- | -------- | ---- | ----------------- |
| `unique_ptr` | 独占      | ❌        | ❌    | 单一资源管理            |
| `shared_ptr` | 共享      | ✅        | ✅    | 多模块共享对象           |
| `weak_ptr`   | 观察（不拥有） | ✅        | ❌    | 避免循环引用            |
| `auto_ptr`   | 独占（旧）   | ❌（复制会转移） | ❌    | 已弃用，替代 unique_ptr |

---

### 一句话总结

> 智能指针通过 **自动管理动态资源**，避免手动 `delete`，
> `unique_ptr` 独占、`shared_ptr` 共享、`weak_ptr` 辅助观察，而 `auto_ptr` 已废弃。
