C++20 是 C++ 的又一次重要标准更新，带来了**语言特性、库增强、并发和概念化**等多方面改进，使 C++ 更现代化、可读性和安全性更高。以下整理核心新特性：

---

### 1. 语言特性

1. **概念（Concepts）**

    * 用于约束模板参数类型，提升模板可读性和报错信息

   ```cpp
   template<typename T>
   concept Incrementable = requires(T x) { x++; };

   template<Incrementable T>
   void func(T t) { t++; }
   ```

2. **范围 `ranges` 与视图（Ranges & Views）**

    * 提供惰性序列操作、类似 STL 的流式接口

   ```cpp
   #include <ranges>
   for (int i : std::views::iota(1,10) | std::views::filter([](int x){ return x%2==0; }))
       std::cout << i << " ";
   ```

3. **三向比较运算符（Spaceship Operator `<=>`）**

    * 自动生成比较操作符，实现全序关系

   ```cpp
   struct Point { int x,y; auto operator<=>(const Point&) const = default; };
   ```

4. **模块化（Modules）**

    * 替代传统头文件，减少编译时间，提高封装性

   ```cpp
   export module mymodule;
   export void func();
   ```

5. **协程（Coroutines）**

    * 支持异步任务与生成器风格代码

   ```cpp
   #include <coroutine>
   std::generator<int> counter() { for(int i=0;i<10;i++) co_yield i; }
   ```

6. **模板参数包改进**

    * 支持 `template<class T> requires`、`consteval` 等

7. **`consteval` 与 `constinit`**

    * `consteval`：必须在编译期求值
    * `constinit`：确保变量静态初始化

8. **`[[likely]]` / `[[unlikely]]` 分支预测提示**

   ```cpp
   if ([[likely]] x > 0) { ... }
   ```

9. **改进的 `lambda`**

    * 可使用模板参数、捕获 `*this`

   ```cpp
   auto l = [*this](int x){ return member + x; };
   ```

---

### 2. 标准库新特性

1. **`std::span`**

    * 非拥有型数组视图，轻量、安全

   ```cpp
   void print(std::span<int> arr) { for(auto v : arr) std::cout << v << " "; }
   ```

2. **`std::atomic` 改进**

    * 支持 `std::atomic_ref`，提供引用原子操作
3. **同步与并发**

    * 信号量：`std::counting_semaphore`, `std::binary_semaphore`
    * 屏障（Barrier）：`std::barrier`
    * latches：`std::latch`

4. **`std::format`**

    * 类型安全、Python 风格字符串格式化

   ```cpp
   #include <format>
   std::cout << std::format("Hello {}!", "World");
   ```

5. **`std::chrono` 改进**

    * 时钟和日历支持，`std::chrono::year_month_day` 等

6. **Ranges 库**

    * `std::ranges::sort`, `std::views::filter`, `std::views::transform`

7. **`std::bit_cast`、`std::bit`**

    * 安全类型重解释、位操作工具

---

### 3. 其他增强

* **字符串字面量改进**：`u8"..."` UTF-8 字符串
* **`[[no_unique_address]]`**：空成员优化
* **更严格的模板类型推导和约束检查**

---

### 4. 一句话总结

> C++20 通过 **概念、范围、协程、模块、格式化库和并发增强**，
> 大幅提升模板安全性、可读性和现代化编程能力，是 C++ 现代标准的重要里程碑。

可结合 **嵌入式高性能控制、机器人异步任务、并行计算和泛型库** 等场景说明应用。
