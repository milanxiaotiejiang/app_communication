在 C / C++ 中，`union` 用于**让多个成员共享同一块内存**，任一时刻**只有一个成员是“有效的”**，核心目标是**内存复用与底层表达**。

---

### 1. 基本特性

```cpp
union U {
    int   i;
    float f;
    char  c[4];
};
```

* 所有成员起始地址相同
* 大小 = 最大成员大小（受对齐影响）
* 同一时间只能安全使用一个成员

---

### 2. 内存模型直观理解

```
|<------ 4 bytes ------>|
+-----------------------+
| i / f / c[0..3]       |
+-----------------------+
```

---

### 3. 读写规则（重要）

* **最后写入的成员，才是当前有效成员**
* 读写不同成员 → **未定义行为**（部分特例除外）

合法：

```cpp
U u;
u.i = 10;
```

非法：

```cpp
float x = u.f; // 未定义行为
```

---

### 4. C++11 之后的变化

C++11 起：

* `union` 可以包含构造 / 析构
* 可以包含非平凡类型（需手动管理生命周期）

```cpp
union U {
    int i;
    std::string s;
    U() {}
    ~U() {}
};
```

需显式构造 / 析构：

```cpp
new (&u.s) std::string("hi");
u.s.~basic_string();
```

---

### 5. 常见安全用法

#### 5.1 与 `enum` 搭配（标签联合）

```cpp
enum Type { INT, FLOAT };

struct Value {
    Type type;
    union {
        int   i;
        float f;
    };
};
```

明确当前有效成员。

---

#### 5.2 类型重解释（受限）

```cpp
union U {
    uint32_t i;
    float    f;
};
```

仅在特定 ABI / 平台下可用，现代 C++ 更推荐：

```cpp
std::memcpy
std::bit_cast (C++20)
```

---

### 6. `union` 的典型应用场景

* 协议解析 / 数据帧
* 变体类型（早期实现）
* 硬件寄存器映射
* 内存极度受限的嵌入式系统

---

### 7. 与 `struct` 的对比

| 项目   | struct | union |
| ---- | ------ | ----- |
| 成员存储 | 各自独立   | 共享内存  |
| 同时有效 | 全部     | 仅一个   |
| 使用难度 | 低      | 高     |
| 安全性  | 高      | 低     |

---

### 8. 现代替代方案

* `std::variant`：类型安全
* `std::optional`：单值可选
* `std::any`：类型擦除

---

### 一句话总结

> `union` 是**对内存布局的直接控制**，
> 强大但危险，应在边界清晰的底层场景中使用。
